01 A little background

What is an API, anyway?

It is simply a way for two programs to talk to each other. MAF asks your chosen AI service to do some work, then brings the answer back to you.

API
Short for Application Programming Interface. Think of it as the connection between MAF and a service such as OpenAI.
API key
Your private access pass. It identifies your provider account, so someone who has it could use your allowance or run up charges.

A provider is the company supplying the service. A model is the particular AI you choose from that provider. Your key is not your account password, email address or a MAF licence code.

IntelligenceStart here

Business analysis, ideas, writing and refinement. This is the only connection required for AI work.

Web searchOptional

Current web research through Tavily. Without it, MAF works from the information you supply.

Image generationOptional

Creates images when requested. Leave it unconfigured if you only want text.

There is no MAF account to create.

MAF has no login or internal credit balance. You sign in to the provider’s website to manage its account, billing and keys. This guide does not collect any keys.

02 Before you spend

You choose the service.
You pay for its usage.

Your existing MAF purchase does not pay your provider bills. Check costs before you connect, and start small.

A chat subscription is not an API balance.

Do not assume ChatGPT, Claude or Gemini subscriptions cover MAF requests. MAF uses API keys, not your chat subscription sign-in. OpenAI explains the distinction.

  1. Check current API prices. Some providers have a limited free allowance. Not everything is free, and models have different prices.
  2. Choose a small starting balance or spending limit. Pick an amount you are comfortable with and turn on usage alerts where available.
  3. Check automatic top-ups. Leave them off unless you deliberately want your payment method charged again when funds run low.
  4. Check usage after your first small task. Use the provider’s billing or usage dashboard before generating more.

Know the difference

An alert tells you.

A budget alert sends a warning. It does not stop spending. A hard limit can stop requests, but enforcement may have a short delay. Check the provider’s controls.

Know what adds up

One click can mean several calls.

Drafting, review and refinement can each use AI. Regenerating, repurposing and images add usage. A failed task does not necessarily mean there was no charge.

Text AI is commonly billed in tokens, small pieces of text it reads and writes. There is no fixed price per post. See current OpenAI API prices if using OpenAI.

Leave Visual Identity for later if you are learning.

A full Visual Identity run can create 12 provider-billed images. It is optional and can be skipped.

03 On your provider’s website

Create your first key.

We will use OpenAI as the example. You do not have to use it, and this is not a claim that it is cheapest.

If you already use another supported provider, see other Intelligence providers, then return to connecting MAF.

  1. Open the API platform

    Go to OpenAI’s API platform ↗ and sign in or create your own account. This is the API platform, not the ChatGPT conversation screen.

  2. Set up billing carefully

    Open API billing ↗. Follow the instructions to enable API usage and add funds or a payment method if required. Read minimum-payment, expiry and recharge terms before paying.

  3. Create a key you can recognise

    Open API keys ↗. Select your project, or create one called MAF V3 if offered. A project groups related usage and settings.

    Choose the option to create a new secret key and name it MAF V3 on my PC. Use a normal project key, not an Admin key. Allow only the functions you need where permissions are offered. A read-only key cannot generate content.

  4. Copy it privately

    Copy the complete secret. If you want to keep a copy, use a trusted password manager. Providers may show the full key only once. Record any expiry date so you can replace it before it stops working.

  5. Come back to the MAF app

    Follow the next section. You do not need the code, terminal commands or npm installations shown in provider developer tutorials.

Your helper does not need your key.

Never send it to Evolution Unleashed, an AI chat or someone helping you. Enter it yourself in MAF. Pause screen sharing or recording while a key is visible.

04 Back in the MAF app

Make the connection.

Open MAF V3 from the Windows Start menu. First launch takes you to API integrations. From the dashboard, choose Integrations.

MAF V3→API integrations→Intelligence

  1. Choose the provider first

    In the Intelligence card, select OpenAI or compatible, then OpenAI preset for an OpenAI key. Choose the provider and preset before pasting the key.

  2. Keep the preset address

    Leave Base URL at https://api.openai.com/v1. This is where your requests and key will be sent. Never replace it with an address supplied by a stranger.

  3. Check the model

    The preset fills in Model. Use it if your account has access, or enter an available, compatible text model from your provider. Names and availability can change.

  4. Paste your key into MAF

    Click the app’s API key field and paste with Ctrl + V. Paste only the complete key, without quotation marks, extra spaces or an example command. There is no key field in this guide.

  5. Enable, save and test

    Turn on Enable this capability. Choose Save & test once and wait. This sends a real request and may incur a small provider charge.

  6. Look for Verified

    Once Intelligence says Verified, choose Continue setup and follow the checklist into BUILD. Only Intelligence needs to be verified; the other two cards can remain unconfigured.

A blank key box after saving is normal.

MAF hides the full saved key and shows a masked hint. You do not need to paste it every time. Configured, test needed means the connection still needs a successful test.

Changing the provider or address can clear the draft key; enter the key for the newly selected service. Changing a key, model or address requires a fresh Save & test. If an error appears, use Get unstuck instead of clicking repeatedly.

06 A few rules worth keeping

Keep the key to yourself.

Your key can authorise spending. Protect it even when someone is trying to help you.

Five things never to do

  • Never paste it into a chat. That includes AI agents, email, support tickets, social posts and GitHub issues.
  • Never put it in a screenshot or shared file. Keep it out of recordings, shared documents, source code and public repositories.
  • Never use a random key checker. Avoid unfamiliar websites and tools sent by strangers. Enter your key only in MAF’s intended field or the provider’s official site.
  • Never share, borrow or buy someone else’s key. Use your own account and a separate key for MAF.
  • Never turn off protection to get started. Do not disable antivirus or bypass an actual malware or integrity warning.

Use a strong provider-account password and two-factor authentication where available. Keep Windows and security software updated. Use only the permissions you need, not an administrator key.

After pasting, copy a harmless word to replace the key on your clipboard. If clipboard history is enabled, press Windows + V and delete the key entry, including any pinned copy.

Saved locally is not invulnerable.

MAF saves your work on your computer and encrypts saved keys. Someone or malware with access to your Windows account or complete backup may still obtain them. Protect your computer and backups. Never share the whole app data folder for help.

AI work still leaves your computer.

Relevant business information, prompts or content go to your selected provider. Tavily receives search queries; image providers receive image prompts. Share only material you are entitled to share. Check privacy and retention terms, which can differ between free and paid plans.

If something goes wrong

Think your key was exposed?

  1. Revoke or delete it immediately on the provider’s official API-key page. That stops future use of the key, including by MAF. Deleting a screenshot or message is not enough.
  2. Check usage and billing. Contact the provider about activity you do not recognise.
  3. Secure any compromised computer or account first. Use a trusted device to manage the provider account before creating or entering a new key.
  4. Create a replacement, enter it in the affected MAF card and choose Save & test. Replace it in every card or other app that used the old one.

Pausing or stopping a connection

Clear key removes MAF’s saved copy. It does not revoke the provider key. To pause, turn off Enable this capability and click Save disabled. To retire the key, revoke it with the provider too.

Uninstalling MAF does not cancel provider plans, revoke keys or remove the retained workspace. Manage billing and auto-recharge on the provider’s website.

07 Help when you need it

Let’s get you unstuck.

Choose the message closest to what you see. Fix the cause before retrying, especially when it involves billing.

Invalid key or authentication failed
Check that the key belongs to the selected provider. Copy it again without extra text. If it expired, was revoked or is lost, create a replacement on the provider’s official website.
Quota, balance or billing error
Open the provider’s billing and usage pages. Check funds, limits and API access. A chat subscription is not proof of API balance. Repeated retries will not fix this.
Model not found or access denied
Check the exact model name and your account’s access. Some image models require extra verification. Use an available, compatible model; do not guess names.
Rate limit or timeout
Wait before trying again. Check your internet connection and the provider’s service status. If it continues, try a smaller task.
Disabled or no Continue setup button
Turn Intelligence on, then choose Save & test. Continue setup requires a Verified Intelligence connection. You do not need all three cards configured.
The key box is blank after saving
This is normal. Check the masked hint and Verified status. MAF keeps the full saved key hidden.
If you ask someone for help

Share the provider name, model name, app version and error wording after checking for keys or private content. Never share your key or complete data folder. Billing disputes and account restrictions must be handled with the provider.
